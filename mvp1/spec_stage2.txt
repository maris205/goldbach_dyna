- 𝔖(N) = 2·C2·∏_{p|N, p>2} (p−1)/(p−2)，C2 = ∏_{p>2}(1−1/(p−1)²)；对 N 分解时先去掉因子 2。

D2：时间窗口误差。
- N 取 10^4,10^5,10^6,10^7,10^8 各量级若干偶数：包括 10^m 本身、接近 10^m 的 2 的幂、𝔖 大的 N（如接近 10^m 的 30030 或 510510 的倍数）、以及一个普通偶数。
- k = 1 … π(√N)。G_k^N = {n : gcd(n,P_k)=1 且 gcd(N−n,P_k)=1}，P_k = 前 k 个素数之积。
- E_k(N) = #{0<n<N : n ∈ G_k^N} − N·Haar(G_k^N)，Haar = ∏_{p≤p_k, p|N}(1−1/p) · ∏_{p≤p_k, p∤N}(1−2/p)。
- 计数必须直接筛（独立于 CRT 乘积公式）：建议长度 N 的布尔数组，按素数顺序依次划掉 n≡0 和 n≡N (mod p) 的位置，每个素数只统计新划掉的个数来增量更新计数（总代价 ~N log log N）。10^8 内存可用分段。小 N 可用暴力 gcd 抽查一致。
- 输出 |E_k|/(N·Haar) 对 x = ln P_k / ln N 的表（json）和图（PNG，对数纵轴，每个 N 一条线），标出相对误差首次超过 10% 的临界层 k_c(N) 及对应 x。

D3：对偶数 N 比较 r(N) = #{(p,q) 有序素数对 : p+q=N} 与 𝔖(N)·I(N)，I(N) = ∫_2^{N−2} dt/(log t · log(N−t))。
- 全量做到 N ≤ 10^7（r(N) 可用 FFT 卷积或其他精确方法，务必精确为整数，可抽查暴力值）；10^7 < N ≤ 10^8 用抽样（例如每个子区间几百~几千个 N，含 2 的幂和 30030 的倍数）。如果时间允许也可以更多。
- I(N) 数值积分要精确（相对误差 <1e-6），可用 scipy.quad 或高阶求积；全量时要向量化或插值，但需抽查精度。
- 给出 ratio = r/(𝔖·I) 的均值、方差按量级分段 [10^m,10^{m+1}) 的变化表；列出最小的 20 个比值对应的 N（以及 𝔖(N)、N 的分解），检查是否集中在 𝔖(N) 小的 N（如 2 的幂）；也报告最大的 20 个。可画 ratio 分布图。
