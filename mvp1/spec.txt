约定：P_k = p₁⋯p_k；U_k = {n mod P_k : gcd(n,P_k)=1}；对偶数 N，G_k^N = {n : n ∈ U_k 且 N−n ∈ U_k}。
1. 对 N ∈ {30, 32, 98, 210, 1000, 1024, 2310, 30030, 100000, 510510}、k = 1..7，在 Z/P_k 上枚举，计算 R_k(N) = |G_k^N|/P_k ÷ (|U_k|/P_k)²。断言：R_k(N) = 2 ∏_{3≤p≤p_k, p∤N} (1−2/p)/(1−1/p)² × ∏_{3≤p≤p_k, p|N} p/(p−1)（误差 < 1e−12）。断言：G_k^N 与 {n : n ∈ U_k 且 n−N ∈ U_k} 是同一集合。与极限 𝔖(N) = 2C₂ ∏_{p|N, p>2} (p−1)/(p−2) 比较，C₂ = 0.6601618。
2. 真实计数：r(N) = #{(p,q) 有序 : p+q=N}，与 HL(N) = 𝔖(N) ∫_2^{N−2} dt/(ln t · ln(N−t)) 比较，N = 10⁴ … 10⁶ 若干个。
3. 区间统计：N ∈ [10⁵, 1.1×10⁵) 全部偶数，报告 r/I 与 r/(𝔖·I) 的均值、标准差、与 𝔖 的相关系数（参考值：标准差 0.77 → 0.0185，相关 0.9987）。
4. Legendre 层：k = π(√N) 时 N ∏_{p≤√N} 局部密度 ÷ r(N)，N = 10⁴ … 10⁷；与 4e^{−2γ} = 1.2609 比较（参考：10⁷ 为 1.0988）。
5. 偶数 N ≤ 2×10⁵ 上 𝔖(N) 的均值（参考 1.9868，理论 2）。
