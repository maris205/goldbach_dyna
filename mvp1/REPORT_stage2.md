# 第 2 阶段：预先固定的成功标准

以下标准先于 stage2.py 创建和实验运行写入，运行后仅追加结果，不调整阈值。

1. 文件保护：仅新建文件，不修改任何已有文件；不 commit/push，不联网。记录已有文件 SHA-256，并于结束时核验。
2. D2：在 10^4、10^5、10^6、10^7、10^8 五个目标尺度，各选目标本身、最近的 2 的幂、最近的 30030 倍数、最近的 510510 倍数及一个普通偶数（较小尺度采用最接近的正倍数并披露偏离）。每个 N 完整覆盖前 π(√N) 层。长度 N 的布尔直接筛逐素数记录新删除数，不以 CRT 或 Haar 推算窗口计数；小 N 逐层以独立 gcd 抽查。JSON 保存全部层的 count、Haar、E、相对误差、x=ln(P_k)/ln(N)。报告首次严格超过 10% 的 k_c 和 x；未超过须明确记为空。PNG 使用对数纵轴。
3. D3：全量覆盖 6≤N≤10^7 的偶数；N=2、4 的积分无有效正长度区间，比值未定义，明确排除。用双精度线性 FFT 卷积得到有序对，所有输出距最近整数 <10^-6，检查非负性、对称项奇偶性；N≤2000 全量和较大 N 分层抽样用直接素数筛计数核对。10^7<N≤10^8 在九个等宽子区间各固定随机种子抽取 300 个偶数，并加入区间内全部 2 的幂和 30030 倍数、D2 样本，全部直接计数。
4. I(N)=∫_2^(N−2)1/(ln(t)ln(N−t))dt：用对称变换 t=exp(u) 后 scipy.quad 严格求积建立 log N/log I 三次样条；以独立原变量 scipy.quad 作小值、分层和随机验证。验证最大相对误差须 <10^-6；不通过则加密或直接求积，不放宽标准。
5. 𝔖=2C₂∏(p−1)/(p−2)，C₂=0.6601618158468695739278121100145557784326233602847334。批量乘法筛与先除尽 2 的独立试除分解交叉验证。按 [10^m,10^(m+1)) 报告 ratio 均值、总体方差、样本数与覆盖类型，10^8 端点另列。全量/高段抽样分别及合并列出最小、最大 20 个（含 N、r、I、𝔖、素因数分解）；分析小比值与小 𝔖、2 的幂的关系，不把有限计算当作证明。
6. 报告成功标准达成情况、D2 临界表、D3 分段和最小 20 表、图路径、分项耗时、数值检验、抽样偏差与局限。目标总实验时间不超过 60 分钟，若缩减范围必须明确披露。

首次 D3 建表因节点取对数后重复而停止；对变换后节点去重后重新执行，复用已完成的 D2。该修正未更改判据、范围或精度阈值。PNG 经视觉复核后调整 D3 纵轴以完整显示最高密度峰。
