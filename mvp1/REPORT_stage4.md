### 完成情况与方法

标准 2–6 全部达成：k=1,…,12，全部 1,000,000 个正偶数 N≤2,000,000；五个窗口全部枚举，未截短 [10^6,2×10^6]。文件完整性标准 1 见末尾审计。

主算法先逐素数在布尔数组 A(n) 中划掉倍数；A(1)=1，A(0)=0。只压缩存储奇数 A(2i+1)，其线性自卷积第 j 项恰为 m_k(2j+2)。这是两个布尔存活指示函数的离散求和，没有使用 Haar 预测计数。用模 998244353、原根 3、长度 2^21 的 NTT 整数运算计算，补零避免循环混叠；每个系数≤10^6<模数，因此恢复的是精确整数。int64 模乘最大值小于 10^18，不溢出。

独立 scipy 实数 FFT 比对全部 12,000,000 个系数，全部一致；最大距整数误差 5.82077e-10，最终计数不依赖浮点舍入。另对 1306 个 N、15672 个 (k,N) 逐 N 重新建立长度 N 的布尔数组，依次划掉 n≡0 (mod p) 与 n≡N (mod p) 两类，计数全部一致。含 N≤2000 全量、四层各64个固定种子抽样、全部例外及窗口见证、各 p|N 的小/大样本。抽样仅用于交叉检查，主扫描全量。直接复核点及各层计数全部存于 JSON。未采用 CRT 公式交叉检查。

Haar 以精确有理数计算：共同分母 P_k，分子逐 p 乘 p−1（p|N）或 p−2（p∤N）。每个窗口的归一化最小值由所有偶数的 Python 任意精度整数交叉乘法比较，包含并列计数，故不是浮点候选估计。min m 与 min ratio 分别优化，见证可能不同。

### 数学解释与局限

固定 k 时，对每个 N 的剩余类集合以 P_k 为周期，其一个完整周期存活数恰为 P_k·Haar(G_k^N)。对偶数 N，每个奇素数最多禁两类，2 只禁一类，故该数至少为 1；m_k(N)=N·Haar+O(P_k)，且 N≥P_k 时必含完整周期，因而固定层的空集例外严格有限。这里的 O 常数可取 1，并且这一界不对增长的 k 给出有效一致相对误差。实验与固定层无大例外一致，超出 X 的结论只能依据上述周期论证，不能借有限扫描外推具体最大例外。

“真正哥德巴赫例外来自 k(N)→∞ 时的筛误差与素数定理级误差”须理解为研究方向：固定层放过大量合数和 1；把有限层候选数转成真实素数对，需要随 N 增长的筛深度、处理小素数等边界项，并控制筛余项和素数对分布误差。只有素数定理的一点分布信息并不足以解决二素数相关性/筛的奇偶障碍，不能把这句话当成已证明的误差分解。p_k≥sqrt(N) 时存活的正数除 1 外只能是大于 p_k 的素数，但被筛掉的小素数对仍需单独补回。

本模型的空集与经典哥德巴赫例外不同：例如小素数本身会被本层划掉，而 1 被保留。另以直接埃氏筛独立枚举 N=2,…,100 的全部无序素数对，结果存于 JSON；此有限范围仅 N=2 无素数对（4=2+2，6=3+3），绝不据此断言任意范围的经典例外。没有声称改进任务提到的 Pintz X^0.72 或任何解析例外集上界，也没有核验/引用该文献。
